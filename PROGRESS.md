# Прогресс разработки: Микроядерная ОС на RISC-V & DevSecOps

Файл трекинга разработки ядра операционной системы для целевой платформы **Milk-V Duo** (процессор **Sophgo SG2000**, ядро **XuanTie C906**, архитектура **RV64GCV**).

## 🎯 Спецификация целевой системы
* **Базовый адрес RAM:** `0x80000000`
* **База UART0 (MMIO):** `0x04140000`
* **Режим MMU:** Sv39 Paging (3 уровня таблиц, страницы по 4 КБ)
* **Разделение привилегий:** Изоляция процессов в User Mode (U-mode) через PMP (TOR) и системные вызовы `ecall`.
* **Синхронизация:** Lock-free Ring Buffer (атомарные инструкции `amoswap.w.aq` / `fence`).

- [ ] **CI/CD:** Сборка изолированного `Dockerfile` (Alpine + RISC-V GCC + CMake) для воспроизводимости окружения.

### Этап 5: Форматированный вывод и автодокументация

### Этап 8: User Mode и Расширенный SAST

- [ ] **CI/CD:** Интеграция инструмента `Gitleaks` (или `TruffleHog`) в пайплайн для сканирования коммитов на предмет хардкода приватных ключей/секретов.

### Этап 10: Аппаратная защита PMP и Чат-боты (ChatOps)
- [ ] **Ядро:** Настройка регистров PMP (`pmpcfgX` / `pmpaddrX`) в режиме TOR для изоляции пространства ядра. Перехват исключений `Access Fault`.

### Этап 11: Модульный рефакторинг и Продвинутый GitFlow

- [ ] **CI/CD:** Переход на модель веток `feature/`, `release/`, `master`. Обновление `CMakeLists.txt` под раздельную компиляцию объектных файлов.

### Этап 12: Включение MMU (Режим Sv39) и Эмуляция в CI

- [ ] **CI/CD:** Интеграция эмулятора QEMU в Docker-образ. Настройка CI-шага, запускающего ядро в headless-режиме и валидирующего логи старта MMU.

### Этап 13: Изоляция адресных пространств и E2E-тесты
- [ ] **Ядро:** Смена контекста памяти: подмена регистра `satp` и очистка TLB через `sfence.vma` при переключении задач. Процессы работают по общему виртуальному адресу `0x1000`.
- [ ] **CI/CD:** Написание Python-скрипта на базе `pexpect`, который внутри CI симулирует ввод команд пользователя в Shell ядра и проверяет ответы.

### Этап 14: Оптимизация памяти (Lazy Allocation) и Бинарный комплаенс
- [ ] **Ядро:** Динамическое выделение страниц: таблицы процессов изначально пусты, перехват исключений `Page Fault` (коды 12, 13, 15) и маппинг страниц «на лету» по значению `mtval`.
- [ ] **CI/CD:** Контроль размеров бинарных секций `.text`, `.data`, `.bss` через `riscv64-unknown-elf-size`. Блокировка сборки при превышении лимитов.

### Этап 15: Разделяемая память (Shared Memory) и SCA-анализ
- [ ] **Ядро:** Высокоскоростной межпроцессный транспорт. Отображение одной физической страницы в пространства двух процессов (Writable у Producer, Read-Only у Consumer).
- [ ] **CI/CD:** Внедрение SCA-анализа базовых образов и зависимостей на уязвимости (CVE) через `Trivy`. Автопубликация релизов в Package Registry.

### Этап 16: Трейсинг без UART-задержек и Локальный IaC-стенд
- [ ] **Ядро:** Проектирование неблокирующего циклического лога трассировки ядра (`Trace Buffer`) по атомарным индексам `head`/`tail`.
- [ ] **CI/CD:** Развертывание и связывание в единую локальную сеть всего DevSecOps-комплекса класса из готового файла `docker-compose.yml`.

### Этап 17: Многоядерность (SMP) и Централизованные логи
- [ ] **Ядро:** Ассемблерный запуск второго ядра: снятие сброса с `Hart 1`. Разделение на Compute Core (Core 0) и асинборотный I/O Monitor Core (Core 1).
- [ ] **CI/CD:** Настройка отправки логов стадий сборки и дампов безопасности по API напрямую в `Grafana Loki` (визуализация на порту `3001`).

### Этап 18: Атомарная защита шины и Управление секретами (Vault)
- [ ] **Ядро:** Внедрение встроенных примитивов компилятора (`__atomic`) с барьерами памяти `RELEASE/ACQUIRE` для защиты лога трассировки от коллизий ядер без мьютексов.
- [ ] **CI/CD:** Развертывание `Infisical (Vault)`. Динамический импорт ключей подписи. Расчет SHA256-хэша ядра и генерация цифровой подписи `fip.bin.sig` через OpenSSL.

### Этап 19: Адаптация под железо Sophgo и Сетевой деплой (CD)
- [ ] **Ядро:** Перевод адресов под физическую плату Sophgo SG2000. Упаковка бинарника ядра утилитами SDK в формат загрузчика `fip.bin`.
- [ ] **CI/CD:** Настройка локального Self-Hosted раннера. Автоматический деплой подписанного `fip.bin` на плату Milk-V Duo по USB-сети (`192.168.42.1`) через `scp` с последующим горячим ребутом.

### Этап 20: GitOps-аудит и Автоматизация дефектов

- [ ] **CI/CD:** Сдача сквозного пайплайна. Интеграция автоматического заведения карточек багов в `MantisBT` по API из Semgrep/SAST. Связывание RSS-ленты Mantis с Mattermost.
